Pester no informa metricas independientes de lineas, funciones o ramas. Node no
informa sentencias por separado. No se inventan esas cifras. AltCover agrega en
su resumen una rama ficticia a metodos sin BranchPoint; el gate lee todos sus
puntos reales y rechaza cualquier contador sin visitar. El fuente C# no cambia
para instrumentarse, se compila con dobles de fronteras externas. La integracion
real de WinForms y del apagado de arboles sinteticos se conserva aparte.

La excepcion AppleScript corresponde a una interfaz/motor ausente: no se afirma
que ejecutar el stub de osacompile sea ejecutar AppleScript. Compilacion e
interaccion nativas de esa UI requieren macOS y siguen registradas como
validacion de plataforma pendiente. Ningun modulo instrumentable se omite.

## Reproduccion y proteccion del gate

- `npm ci --ignore-scripts`; `python -m pip install -r requirements-dev.txt`.
- Rapidas: `npm test`. Cobertura completa: `npm run test:coverage`.
- Integracion nativa real adicional: `npm run test:windows`.
- Los gates rechazan cada archivo ausente, cada punto sin cubrir y fracciones que
  un resumen redondearia al 100%. Pruebas del gate incluyen LCOV corrupto,
  archivos nunca cargados y 99.999% con un punto faltante.
- Bash tiene un inventario revisado de comandos independiente de su traza y
  hashes congelados; comando nuevo, faltante o archivo nuevo falla el gate.
- Los fuentes PowerShell se copian sin cambios a una raiz temporal y se
  comprueban sus hashes antes de aceptar el reporte de Pester.
- Todas las pruebas usan DB/config/HOME/procesos y transportes sinteticos;
  ninguna necesita secretos, Telegram real ni iniciar la instancia habitual.
- Reportes y binarios locales ignorados bajo data/. No se publican datos ni
  rutas personales en el informe versionado.

## Cambios y revision

- JSDOM y herramientas de cobertura solo en desarrollo, con versiones fijadas.
- Inyeccion de importadores en ComicTrackerService conserva las implementaciones
  predeterminadas; permite probar su orquestacion real sin conexiones externas.
- Regresiones corregidas con pruebas: campos wiki vacios, cancelacion de cierre
  PowerShell tras error de apagado, ruta Linux con espacios y conservacion del
  scheduler para reintentar cuando falla el apagado de Telegram.
- Limpieza de guardas privadas imposibles respaldada por los invariantes de los
  llamadores; API publica y caminos nulos/errores alcanzables conservados.
- Revision independiente: sin hallazgos accionables sobre produccion ni gates.
- CI por push/PR: solo gates rapidos; las pruebas POSIX lentas y WinForms reales
  adicionales son manuales (`workflow_dispatch`, opcion full). No sondeos CI.
